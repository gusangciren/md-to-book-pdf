# 固定排版设计规范｜禁止随意修改

## 字体

全书统一：LXGW WenKai 霞鹜文楷；目录、章节扉页、正文、页脚全部使用该字体。
> 封面页（如有）同样使用霞鹜文楷。需本机已安装该字体。

## PDF 最终目标效果

- PDF 正文实际字号：12pt
  > Edge 打印存在缩放，HTML CSS 设置为 14pt，渲染后 PDF 得到 12pt 正文；不要直接 CSS 写 12pt。
- 行间距：1.95 倍；正文两端对齐
- 页面边距：上下 24mm，左右 26mm
- 页面底色：#FBF7EE（米白），由 PyMuPDF 在 PDF **内容流最底层**绘制（CSS 背景在打印时无效；直接 draw_rect 会盖住正文）

## 图片强制规则

1. 最大宽度占可用页面 88%；最大高度 130mm
2. object-fit: contain，完整保留图片全部内容，严禁裁切
3. 圆角 10px
4. 图片居中，不超出页边距

## 超链接样式

颜色 #1a5fb4；粗体；下划线；后缀追加 ↗
目录页底部固定提示文本：`按住 Ctrl 键，同时点击文中蓝色链接即可跳转阅读`

**PDF 侧边栏书签**：`finalize_book.py` 传 `--toc-json` 时用 `doc.set_toc()` 写入章节大纲，
层级为 书名 → 目录 → 各章节。目录页里的蓝色链接供页内跳转，书签供阅读器侧边栏与
「跳转到章节」使用，两者并存。页码越界的条目会被丢弃，避免打不开的书签。

## 章节扉页（「闭环」编辑风，每章独占一页）

每章一章页，前后强制分页（page-break-before/after: always），**左对齐**，自上而下：

1. kicker 小字：书名或系列名（12pt，字距 0.4em，金色 #c08b33；`--series` 可自定义）
2. 金色大数字：章节序号（76pt 粗体金色，不加前导零）
3. 章节标题：深墨绿 #1f3d2b（21pt，字距 0.06em）
4. 短金线：110×2px
- 顶部留白：padding-top **66mm**（内容块从页面约 1/3 处开始，视觉重心居中偏上；用户明确要求不要太靠顶）

## 引用块

**朴素缩进式**（用户明确要求，勿加竖线/底色/边框）：仅左缩进 1.2em，文字继承正文色，上下 1.2em 外边距。

## 页脚

格式：`{书籍标题} · {页码}`；封面页（如果存在）不输出页脚页码。

## 配色

主色调：深墨绿 #1f3d2b；强调色：金色 #b8860b；链接蓝 #1a5fb4；正文 #2b2b26

## 自动生成封面规范（「安静编辑感」版式）

封面是**独立整页 SVG**（viewBox 794×1123，A4 @96dpi），以 data URI 内嵌进 HTML，不用 CSS 背景（打印会丢）。参考图：`references/cover-style-light-jcurve.png` / `cover-style-forest-path.png` / `cover-style-navy-stairs.png` / `cover-style-light-series.png`。

### 封面必须满版出血（不得留白边）

封面页/封底页用 CSS 命名页把页边距清零，再让图按整版尺寸铺开：

```css
@page cover { size: A4; margin: 0; }
.cover-page { page: cover; page-break-after: always; }
.cover-page img { width: 100%; height: 100%; max-width: none; max-height: none;
                  object-fit: cover; border-radius: 0; display: block; margin: 0; }
body { margin: 0; padding: 0; }
```

- `body` 的默认 8px 外边距（≈2.12mm）必须清零，否则四边出现米白缝。
- 用 `width/height:100%` 而非固定 `210mm/297mm`：Edge 打印缩放取整会给固定尺寸留约 1.8mm 缝。
- 封面图 viewBox 是 794×1123，与 A4 比例一致，因此 `object-fit:cover` 不会裁掉内容。
- **禁止**用负 margin（`margin:-24mm -26mm`）补偿——只能消掉左/上边距，右/下消不掉。

### 统一版式（自上而下，全部居左，左边距 92px）

1. 左上角 kicker 小字（26px，字距 6，默认「{作者} · 著」）
2. 书名：霞鹜文楷超大字居左（≤6 字/行 **104px** 字距 6；7 字 **90px** 字距 2；8 字+ 78px 字距 2；自动按每行 7 字换行，可用 `\n` 手动断行，禁止单字成行）
3. 金色短线（88×6px）
4. 副标题（29px，字距 8，宽字距小字）
5. 极简线条 motif（**占满中部留白区**，curve 绘图区 x 118–672 / y 620–880，约占页面高 23%）
6. 金边引言块（左侧 4px 金竖线 + 27px 文字，最多两行；**仅封面引言有竖线，正文引用块不要竖线**）
7. 发丝线页脚（1px 横线）+ meta 小字（24px 字距 6）+ 右下小圆环饰件
- light 主题底色带 **feTurbulence 纸纹颗粒**（alpha 0.05，暖灰）+ 左上柔光斑，模拟米白纸张质感

### 三种配色主题

| 主题 | 参数值 | 配色 | 默认 motif |
| --- | --- | --- | --- |
| 米白暖底 | `light`（默认） | 底 #f7f1e4→#ede3cd 暖渐变 + 柔光斑，标题 #2f4a3a，金 #c08b33 | `curve` J 型增长曲线（网格 + 深绿曲线 + 金色端点圆环） |
| 深墨绿 | `forest` | 底 #33543f→#1a3125 渐变，标题 #f2e8d5，金 #cfa14a | `path` 抉择路径（金色节点连线 + 同心圆底纹） |
| 藏蓝 | `navy` | 底 #26415f→#142741 渐变，标题 #f5f2ea，橙 #e0763c | `stairs` 上行阶梯（逐级点标 + 顶端圆环） |
| 墨 | `ink` | 底 #26211c→#100c09 墨黑渐变，标题 #f1e9da，琥珀金 #c8922e | `brush` 书法飞白笔触（左下起笔、向右上挑锋） |
| 酒红 | `wine` | 底 #5a2230→#2c0f17 深酒红渐变，标题 #f3e7d8，金 #caa24b | `constellation` 金线星座（散点 + 细线连接） |
| 中国红 | `red` | 底 #b32430→#6e0b14 渐变，标题 #fffbf2，亮金 #f2c14e | `rings` 同心圆（系列/课程型） |
| 鲜亮红 | `red-bright` | 底 #d62828→#9a1b1b 渐变，标题 #fffbf2，亮金 #f2c14e | `rings` |
| 深红 | `red-deep` | 底 #7a1018→#3d0509 渐变，标题 #fffbf2，亮金 #f2c14e | `rings` |

> **暗底主题必须用矢量 SVG 重生成，不要对已有位图做像素换色。**
> 像素重着色（按颜色距离替换背景）会让圆圈编号等反白文字与重新着色的图形融在一起，
> 文字彻底不可读。改配色一律改 `PALETTES` 后重跑 `build_book.py`。

motif 可用 `--motif` 覆盖（另有 `rings` 同心圆底纹，供系列型封面）。

> **避坑**：自动生成的封面必须与书稿文件夹内已有的封面图在版式、配色、插图上保持明显差异，禁止看起来「把原来的封面复制了上去」。若默认 `light` 主题与现有封面过于相似，应主动选用 `forest` 或 `navy` 等差异显著的主题。

### 系列/课程型变体（参考「闭环」版式）

`--desc`（描述段落，24px 灰调，每行约 26 字）+ `--steps N`（金色数字圆圈一排）+ `--motif rings`；页脚 meta 放「作者 著 · 公众号 ×××」。

### 重新生成

改任意封面参数重跑 build_book.py 即可；封面是独立整页，替换后页码不变，无需重跑 detect_chapters.py。预览用 Edge 截图（`--headless=new --screenshot --window-size=794,1123`），**不要用 PyMuPDF 渲染 SVG**（不支持渐变，背景会变纯黑误导判断）。
