# 示例

`sample.md` 是一份最小可跑的书稿，用来验证 `md-to-book-pdf` 的章节拆分逻辑。

同目录下的 `sample.pdf` 是**跑通后的成品参考**（forest 深墨绿封面，5 页，2 章 + 可点击目录 + 侧边栏书签），先看它就能知道最终效果长什么样——注意封面是**满版铺满整页**的，四边没有白边。

它刻意用了**中文书稿最常见的写法**：

- 顶部 `# 书名` + 一段 frontmatter 引用；
- 一个 `## 目录` 及其列表（应被自动跳过，不当成章节）；
- 正文用 `## 第 N 章` 分级。

## 跑一下

```bash
cd ..
python scripts/make_book.py \
  --md-file examples/sample.md \
  --split-by h2 \
  --title "像企业家一样写作" \
  --author "示例作者" \
  --cover-style forest \
  --out examples/sample.pdf
```

预期结果：

- 封面 1 页（forest 深墨绿主题，**满版铺满整页、四边 0mm**）
- 目录页（来自 `## 目录`，不计入正文章节）
- 第一章、第二章各占一页（章节扉页 + 正文）
- 页脚 `{书籍标题} · {页码}`，目录页底部有跳转提示

末尾还会自动打印满版校验结果：

```
左边留白 0.00 mm  [OK]   …
[通过] 封面满版铺满整页（四边留白 ≤ 0.5 mm），无白边。
```

如果 `## 目录` 被当成了「第一章」，说明 `--split-by` 没传 `h2`；加上即可。
若校验报出几毫米的留白，说明封面 CSS 被改坏了，见 SKILL.md 踩坑第 7 条。
